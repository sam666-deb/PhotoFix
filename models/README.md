# Bundled models

- `face_detection_yunet_2023mar.onnx`: YuNet face detector (Shiqi Yu et al.), from the OpenCV model zoo
  (https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet). MIT License,
  Copyright (c) 2020 Shiqi Yu. The guardrail uses it to check skin tones only inside faces.

Trained PhotoFix checkpoints live in `checkpoints/` (gitignored; see the README for how to train them).
