    Applied edits

      How it works: a neural analyzer detects 7 kinds of problems, a NAFNet restorer removes noise and blur, rules or a learned 3D LUT fix color and tone, and a guardrail checks the result for over-editing before you see it. Code, benchmarks and write-up on GitHub.

      Photos are processed in memory and never stored. The Pro style was trained on MIT-Adobe FiveK (research use only) and is offered here as a non-commercial demo. Example photos: CC0, via Wikimedia Commons ().
